# Sperin Certificates

Standalone installable PWA for UK electrical, emergency-lighting and domestic smoke-alarm certification.

Included workflows:
- Electrical Installation Certificate (BS 7671:2018+A4:2026-aligned)
- Electrical Installation Condition Report (BS 7671:2018+A4:2026-aligned)
- Minor Electrical Installation Works Certificate
- Emergency Lighting Certificate (completion / periodic / small-installation workflows)
- Domestic Fire Detection / Household Smoke Alarm Certificate

The application stores drafts locally in the browser, supports JSON backup/restore and client-side PDF export with print-to-PDF fallback.

This is independent software. It does not reproduce NICEIC branding and does not issue an official NICEIC-branded certificate.
