# Certificate audit and section-page candidate — 12 November 2026

Status: local development candidate, not an issued or installed release. Based on v215 branch commit 16d0568. No customer records, storage namespaces, signing configuration, package ID or releases changed.

## Implemented

- Quick Entry renders one selected section, with top navigation and Previous/Next controls across all nine schemas. Section switches save the model. Review links select the containing section, and the saved view retains its section index.
- EICR C1/C2 and C3/FI groups begin on separate pages. Long groups continue, repeat column headings and preserve original observation/edit indices. Existing item numbers are retained; missing numbers fall back to original observation positions. Numbering is calculated after rendering.
- EICR declaration sections can continue without the former hard failure at two pages. Section J follows them and observations follow J. The observation legend follows its actual starting page.
- EICR explicit earthing/bonding choices preserve old false checkbox values as unanswered. No is not inferred from a legacy unchecked box. Bonding service entries print vertically.
- EIC uses larger text and flowing sections. Declaration references identify Amendment 4. Specialist record rows use larger text and preserve numeric zero. Report metadata no longer overlaps document titles.
- Minor Works uses expanding table rows instead of fixed boxes that overlapped and clipped recorded information. Unusually long answers continue across pages. The remaining fixed-field renderer also has continuation support.
- Corrected emergency-lighting standard identifier to BS 5266-1:2025.

## Further verified corrections

- Minor Works: added the amendment-date entry and an explicit other-bonded-services description. Source: IET A4 MEIWC parts 1 and 2, https://electrical.theiet.org/media/f0hlqxq1/bs7671_meiwc_a4.pdf.
- EIC: removed the single-signatory qualification prompt, which is absent from the model signatory fields. Existing stored values remain untouched.
- PAT repair register: added equipment description to the actual repair table (IET V4). A description column elsewhere did not meet that requirement. Source: https://electrical.theiet.org/media/2623/all-forms-copisitee.pdf.
- Domestic alarms: added LD2 protected areas and instructions recipient. Source: Aico installation certificate Issue 7, https://www.aico.co.uk/wp-content/uploads/2021/06/Aico-Smoke-and-Heat-Alarm-Installation-Certificate-Issue-7.pdf. This adapted reference supports specified D/F grades; it is not proof of all Grade A/C requirements. Its manufacturer-specific variation is deliberately not automatically declared.
- Generic PDFs now honour conditional field visibility, matching input screens.
